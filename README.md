# VWF

شروع پروژه اندرویدی VWF.

## ساختار فعلی
- فقط یک نوار در بالای صفحه ساخته شده است.
- نوار شامل دقیقاً شش دکمه است:
  1. Import Video
  2. Export video
  3. Delete
  4. Color And Light
  5. Tracks
  6. Cut Tool
- دکمه‌ها بدون فاصله و حاشیه افقی اضافی کنار هم قرار گرفته‌اند.
- مجموع عرض ناحیه دکمه‌ها ۸۰٪ عرض نوار است.
- ۲۰٪ سمت راست نوار عمداً خالی باقی می‌ماند.
- سایر بخش‌های برنامه فعلاً ساخته نشده‌اند.

## ساخت
پروژه را در Android Studio باز کنید و با JDK 17 و Android SDK 35 همگام‌سازی و Build کنید.
فایل‌های GitHub Actions یا YAML عمداً اضافه یا تغییر داده نشده‌اند.
